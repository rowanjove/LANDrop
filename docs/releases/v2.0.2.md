# LANDrop 2.0.2

## 中文

这是一个以品牌资源和发布包为重点的维护版本，不改变文件、文本、剪贴板和局域网传输协议的功能行为。

### 变更

- 重新设计应用图标：以连续双向环带、文件页和局域网节点表达设备间传递。
- 同步 Web favicon、Web Header、Windows `.ico` 和 Windows EXE 资源图标。
- 更新程序、Web 包和发布包版本号至 `2.0.2`。
- 重新生成 Windows amd64、macOS amd64/arm64、Linux amd64/arm64 发布压缩包，并提供 `SHA256SUMS.txt`。

### 验证

- `npm run typecheck`
- `npm run build`
- `go test ./...`
- `go vet ./...`
- `go build`
- Windows EXE 图标资源提取后与 `assets/landrop.ico` 校验和一致

## English

LANDrop 2.0.2 is a maintenance release focused on branding assets and release packaging. It does not change file, text, clipboard, or local-network transfer behavior.

### Changes

- Redesigned the application icon around a continuous two-way transfer loop, a file page, and local-network nodes.
- Synchronized the Web favicon, Web Header, Windows `.ico`, and Windows EXE icon resources.
- Updated the application, Web package, and release package version to `2.0.2`.
- Regenerated release archives for Windows amd64, macOS amd64/arm64, and Linux amd64/arm64 with `SHA256SUMS.txt`.

### Verification

- `npm run typecheck`
- `npm run build`
- `go test ./...`
- `go vet ./...`
- `go build`
- Extracted Windows EXE icon resource matches `assets/landrop.ico` by checksum
