# LANDrop 2.0.0

## 中文

LANDrop 2.0.0 完成了 Web 界面、传输模型和命令行体验的整体重构。

### 主要更新

- 使用 Preact、TypeScript 和模块化 CSS 重建 Web 界面，统一桌面端与移动端体验。
- 新增文件发送队列，选择文件后可继续添加、移除或清空，确认后才开始上传。
- 新增多文件传输模型，可单独下载文件，也可按需下载 ZIP。
- 新增独立接收页面 `/r/:token`，支持文件和文本预览、复制及下载。
- 完善传输状态、进度、取消、过期清理、断点续传和一次性链接生命周期。
- 设置改为后端持久化，设备名、主题与语言在刷新和重启后保留。
- mDNS 会同步服务协议，设备跳转与二维码能够正确使用 HTTP 或 HTTPS 地址。
- 双击 `landrop.exe` 或运行 `landrop serve` 后会自动打开浏览器；终端提示和帮助改为中文为主。
- 加固文件名、下载响应、PIN 页面和一次性令牌处理，并补充针对性回归测试。

### 下载

本次 Release 提供：

- Windows amd64
- macOS amd64 / arm64
- Linux amd64 / arm64
- `SHA256SUMS.txt` 完整性校验文件

### 验证

- `go test ./...`

- `go build .`
- `npm run typecheck`
- `npm run build`
- `npm audit --omit=dev --audit-level=high`

### 使用提示

- HTTPS 使用临时自签名证书，浏览器首次访问会显示证书警告。
- LANDrop 面向可信局域网使用，请勿直接把服务端口暴露到公网。
- 浏览器自动打开失败时，终端仍会显示可手动访问的地址和二维码。

## English

LANDrop 2.0.0 is a full refresh of the web interface, transfer model, and command-line experience.

### Highlights

- Rebuilt the web interface with Preact, TypeScript, and modular CSS for a shared desktop and mobile experience.
- Added a file queue so files can be added, removed, or cleared before an upload starts.
- Added multi-file transfers with individual downloads and an optional ZIP download.
- Added a dedicated `/r/:token` receive page for file and text previews, copying, and downloads.
- Improved transfer status, progress, cancellation, expiry cleanup, resume support, and one-time token lifecycle handling.
- Persisted device name, theme, and language settings on the backend.
- Advertised the correct HTTP or HTTPS scheme through mDNS for device links and QR codes.
- Automatically opens the browser when `landrop.exe` or `landrop serve` starts; terminal output is now Chinese-first.
- Hardened filename handling, download responses, PIN pages, and one-time token behavior with focused regression tests.

### Downloads

This release includes Windows amd64, macOS amd64/arm64, Linux amd64/arm64, and `SHA256SUMS.txt`.

### Notes

- HTTPS uses a temporary self-signed certificate, so browsers will show a warning on first access.
- LANDrop is intended for trusted local networks; do not expose its service port directly to the public internet.
- If the browser cannot be opened automatically, the terminal still prints the address and QR code.
