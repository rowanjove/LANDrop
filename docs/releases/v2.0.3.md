# LANDrop 2.0.3

## 中文

LANDrop 2.0.3 是一个功能体验与系统加固版本。本次更新新增移动端 Web 设备自动发现与在线感知，完善前端待下载提取流程，全面升级网页端图标体系，并修复了多项网络与状态同步边界问题。

### 主要变更

- **Web 设备自动发现与状态感知**：手机、平板等移动端扫码连接后，服务端通过 SSE 实时感知并识别 User-Agent（iOS、Android、macOS、Windows、Linux、Web），主界面即刻显示对应在线节点，离线自动标记。
- **待下载文件与消息卡片**：主页新增待提取内容卡片，收到的文件支持一键下载，文本内容可直接查看或复制。
- **前端页面图标体系全面更新**：
  - 补充 `favicon.ico` 静态资源，修正浏览器标签页图标显示。
  - 修复深层路由与分享链接（`/r/:token`、`/activity/`）下头部 Logo 相对路径 404 导致的图标碎裂问题。
  - 在设备列表中新增移动端（`IconMobile`）、网页端（`IconGlobe`）专属图标与在线状态角标，与传输列表保持统一视觉规范。
  - 规范文本接收页面图标为 `IconText`，统一页面颜色 Token。
- **网络与状态协同边界修复**：
  - 针对双栈网络的 IPv4-mapped IPv6 客户端地址自动解包清洗，避免地址解析偏差与显示脏数据。
  - 修复多台同机型设备同时连接时的状态覆盖问题，严格基于唯一网络地址管理设备。
  - 补齐前端对传输取消事件（`transfer_cancelled`）的实时监听。
  - 稳定活跃传输列表排序，避免界面重刷时的元素跳动。
- **开发与交付文件清理**：移除内部开发说明与冗余文件，确保发布内容精简安全。
