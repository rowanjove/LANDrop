# LANDrop 2.0.4

## 中文

LANDrop 2.0.4 是一个重要的体验与稳定性升级版本。本次更新新增 Windows 系统托盘与后台静默常驻支持、单实例守护管理、Web 端双栏卡片化界面重构、智能物理网卡识别与多 IP 适配，并完成了全方位的安全加固与传输性能优化。

### 主要变更

- **Windows 系统托盘与后台常驻**：
  - 启动后自动隐藏控制台黑框窗口并常驻系统托盘，避免误关；右键托盘图标可快速打开网页界面、复制局域网访问地址、自由切换控制台显隐或安全退出。
  - 支持 `--console`（保留控制台黑框）和 `--no-tray`（禁用系统托盘）参数供开发者与脚本选用。
- **单实例运行管理**：
  - 基于 PID 文件与本地关闭协议实现跨进程互斥守护，避免重复启动导致端口占用报错；支持对旧实例的平滑接管与安全退出。
- **Web 端双栏卡片化界面重构**：
  - 桌面端升级为双列响应式网格：左栏并列“文件传输”与“文本与剪贴板”卡片，操作集中且直观；右栏展示“附近设备”与“本次传输”待下载项目。
  - 本机设备在设备列表中始终高亮置顶并标注“本机”徽章，解决多设备间自混淆问题。
  - 移动端自动切换为流式垂直单列布局，底部保留便捷的“发送 / 传输历史”移动导航。
- **智能网卡探测与多 IP 识别**：
  - 自动识别并过滤 Docker、WSL、VMware、VirtualBox、Tailscale、Hyper-V 等虚拟网卡，优先绑定真实物理局域网 IPv4。
  - 控制台同步展示所有可用备用局域网 IP 地址，跨网段、多网卡环境下连接更可靠。
- **性能与安全加固**：
  - 多文件与目录下载全面升级为 `zip.Store` 零压缩流式透传，大幅降低主机 CPU 占用，传输直接跑满局域网线速。
  - PIN 码校验升级为 `crypto/subtle.ConstantTimeCompare` 恒定时间比较，防止侧信道时序探测，并加入连续错误指数退避锁定机制。
  - 剪贴板复制增加非安全环境（HTTP）下的优雅降级容错机制。
  - 多文件传输中同名文件自动追加序号去重，杜绝文件覆盖风险。
  - 本地运行日志支持 10MB 自动轮转并严密兼容 Windows 文件系统。
  - 设置页面新增一键“检查更新”功能，直连 GitHub Releases 获取最新版本。
