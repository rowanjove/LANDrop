# LANDrop 2.0.1

## 中文

这是一个不改变功能的维护版本，重点修复公开发布材料中的隐私与文档问题。

### 界面截图

### 变更

- 移除公开仓库中的内部产品需求文档（PRD）及其 README 入口。
- 将实施文档中的个人设备名替换为通用示例名称，并统一示例地址。
- 修正界面截图的文件扩展名，使扩展名与实际 JPEG 编码一致。
- 保留 LANDrop 2.0 的全部功能与安全边界；功能变更请参阅 [v2.0.0 更新说明](v2.0.0.md)。

### 验证

- `go test ./...`
- `go vet ./...`
- `go build .`
- `npm run typecheck`
- `npm run build`
- `npm audit --omit=dev --audit-level=high`
- 公开分支与 Release 附件隐私扫描

## English

LANDrop 2.0.1 is a maintenance release with no functional changes. It cleans up privacy-sensitive examples and internal planning material from the public repository.

### Screenshots

Desktop:

![LANDrop 2.0 desktop home page](https://raw.githubusercontent.com/rowanjove/LANDrop/v2.0.1/docs/screenshots/landrop-2.0-desktop.jpg)

Mobile:

### Changes

- Removed the internal product requirements document (PRD) and its README links.
- Replaced the personal device name in implementation notes with generic examples and normalized sample addresses.
- Corrected the screenshot file extensions to match their JPEG encoding.
- Preserved all LANDrop 2.0 functionality and security boundaries; see the [v2.0.0 release notes](v2.0.0.md) for the feature release.

### Verification

- `go test ./...`
- `go vet ./...`
- `go build .`
- `npm run typecheck`
- `npm run build`
- `npm audit --omit=dev --audit-level=high`
- Privacy scan of the public branch and release assets
